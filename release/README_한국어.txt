스타폭스 커맨드 한글 패치 v1.1
================================

닌텐도 DS "스타폭스 커맨드" 일본판(ASFJ)의 비공식 한국어 팬 패치입니다.
대사는 일본어판 원문을 기준으로 번역했습니다.

제작: arqhive
저장소: https://github.com/arqhive/star-fox-command-korean-translation


1. 준비물
---------
- 원본 일본판 롬 (본인이 소유한 게임에서 직접 덤프한 파일)

  파일명 예 : Star Fox Command (Japan).nds
  크기      : 33,554,432 바이트
  CRC32     : 618C4089
  MD5       : 81d9550164d4c0a3756d1271ee063a1a
  SHA-1     : fe0a3ba974132de5d63429b48ee9d3e8b6d6a318

  ※ 북미판·유럽판 롬에는 적용할 수 없습니다.
  ※ 이전 버전 패치를 적용한 롬에 덧씌울 수 없습니다. 항상 원본에 적용하세요.

- BPS 패치 도구 (아래 중 하나)
  · 웹  : ROM Patcher JS  https://www.marcrobledo.com/RomPatcher.js/
  · PC  : Floating IPS (Flips)


2. 적용 방법
------------
1) 패치 도구를 열고 원본 롬과 StarFoxCommand_KO_v1.1.bps 를 선택합니다.
2) 패치를 적용해 새 롬 파일을 만듭니다.
3) 결과 파일이 아래와 같은지 확인합니다.

   크기   : 33,554,432 바이트 (원본과 같음)
   CRC32  : 2182FDE4
   MD5    : f0ccbdde83e8e17d0235be4304a8029c
   SHA-1  : 0678aca6a45164a555b1c14f35faa0cedd1f0c45

4) 에뮬레이터(melonDS 등), 3DS의 TWiLight Menu++, 또는 플래시카트에서 실행합니다.


3. 한글화 범위
--------------
- 대사 전체 : 스토리, 전투 무전, 작전 화면, 오프닝·엔딩, 적 이름 (약 2,870문장)
- 이미지 글자 496장 : 메뉴, 타이틀, 스테이지 제목, 갤러리, 옵션, Wi-Fi 안내, 작전 화면 등
- 글꼴 : 갈무리 (닌텐도 DS 글꼴 디자인 기반 도트 글꼴)
- 인물·지명 표기는 한국 정식 발매작(스타폭스 2026, 스타폭스 64 3D) 기준
  (안돌프, 팔코 람바디, 라일라트, 카티나 등)
- 닉네임 입력 화면은 영문 자판이 기본으로 뜨도록 수정
- 메뉴(DSi, TWiLight Menu++ 등)에 보이는 게임 이름을 "스타폭스 커맨드"로 변경


v1.1 변경 사항
---------------
- 섹터 선택 제목의 글자 위쪽 잘림 수정
- 작전 메뉴·상태 화면 이름표의 그림자 정리
- 돌아가기 버튼 글꼴 굵기와 아의 도트 획 보정
- 돌아가기·삭제·재시도·마감 글자를 아래로 1px 이동
- 대사·팔레트는 v1.0.3과 동일, ROM 크기 32MB 유지
- 사용자가 최종 수정본의 게임 내 표시를 확인


4. 알려진 문제
--------------
- 일부 작은 이름 목록(칸 높이 7~9px)은 받침이 많은 글자가 뭉개져 보일 수 있습니다.
- 여러 조각을 조합해 보여주는 이미지(라운드 정보 등)는 화면에 따라 어색할 수 있습니다.
- 닉네임은 영문·기호만 입력할 수 있습니다(한글 입력 미지원).
- 게임에서 쓰이지 않는 것으로 보이는 옛 대사 파일(corneria.bmg)은 번역하지 않았습니다.
- 기존 버전 확인 환경 : melonDS, 실기 3DS + TWiLight Menu++ 에서 구동 확인.
  v1.1은 사용자 게임 내 표시 확인을 반영했으며 별도의 실기 재검증은 수행하지 않았습니다.
  DS·DSi 실기와 플래시카트는 확인하지 않았습니다.

이상한 화면이나 어색한 문장을 발견하면 저장소 이슈로 알려 주세요.
