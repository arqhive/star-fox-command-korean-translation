대사 검수를 한 번 더 거쳐 120곳을 다듬은 수정판입니다. 그래픽·글꼴·게임 이름 등 나머지는 v1.0.2와 같습니다.

**원본 일본판에 적용하는 전체 패치입니다.** 이전 한글 패치 롬에 덧씌울 수 없습니다.

## 변경 사항

- 용어를 통일했습니다. `에어리어`는 `지역`으로, `떨어뜨리다`는 `격추하다`로 바꿨습니다.
- 화자별로 존댓말·반말이 어긋난 줄을 바로잡았습니다(예: `괜찮은 거야?`를 `괜찮으신 거예요?`로).
- 어색한 직역과 표현을 다듬었습니다(예: `적 모함을 청소했다`를 `쓸어버렸다`로, `쓸데없는 데서 시간을 잡아먹었군`을 `쓸데없는 일에 시간을 허비했군`으로).
- 대화창을 넘칠 뻔한 한 줄(`무슨 일이라도 생겼으면 어쩌지?`)을 폭에 맞게 조정했습니다.
