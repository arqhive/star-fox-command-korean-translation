롬 안 이미지를 전수 조사해 **아직 일본어로 남아 있던 그림 글씨 32장을 한글화**한 업데이트입니다. 대사와 나머지 게임 데이터는 v1.1과 같고 롬 크기는 32MB 그대로입니다.

**원본 일본판에 적용하는 전체 패치입니다.** 이전 한글 패치 롬에 덧씌울 수 없습니다.

## 변경 사항

롬 안 이미지 1,935장을 모두 디코드해 글자 유무를 확인했고, 게임에서 쓰이는데 빠져 있던 32장을 채웠습니다.

- **작전 화면 튜토리얼 5장** — 비행 루트 그리기, 라운드 캡슐, 임무 완료·실패 조건, 태스크 메뉴 설명.
- **작전 화면 표시 4장** — 적 기지 설명, `? 아이템` 설명, `턴` 표시, 실드 게이지 옆 캐릭터 이름표 42칸.
- **전투 화면 HUD 11장** — 아군 말풍선(폭스·팔코·크리스탈·슬리피·애시), 구조 요청 표시, 이름·항목 목록.
- **멀티플레이 5장** — 배틀 종류 선택과 모드 이름(노멀·팀·캡처 더 플래그·진지 점령).
- **Wi-Fi·다운로드 플레이 4장** — 대전 시작 안내, 무선 통신 불가 안내, 종료 메뉴.
- **옵션 3장** — 데이터·음성 데이터 삭제 확인문, 음성 녹음 제목.

그 밖에 편집에 필요한 텍스처 형식 정보 31개를 도구에 등록했고, `모선` 표기를 다른 화면과 통일했습니다.
