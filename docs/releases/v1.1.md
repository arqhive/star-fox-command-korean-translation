메뉴 그래픽의 글자 잘림과 버튼 정렬을 고친 업데이트입니다. 그래픽 리소스 4개만 바꿨으며, 대사·팔레트와 나머지 게임 데이터는 v1.0.3과 같고 롬 크기는 32MB 그대로입니다.

**원본 일본판에 적용하는 전체 패치입니다.** 이전 한글 패치 롬에 덧씌울 수 없습니다.

## 변경 사항

- 섹터 선택 제목의 편집 영역을 실제 글자 높이에 맞춰 맨 위 획이 잘리지 않게 했습니다.
- 작전 메뉴·상태 화면 이름표의 대각선 그림자를 아래쪽 1px 그림자로 바꿨습니다. 기존 행 높이와 간격은 그대로입니다.
- 공통 버튼 `돌아가기`의 글꼴 굵기를 다른 버튼과 맞추고, 가로 압축으로 변형된 `아`의 세로획과 글자 사이 간격을 도트로 보정했습니다.
- `돌아가기`·`삭제`·`재시도`·`마감`의 글자를 아래로 1px 옮겨 세로 정렬을 맞췄습니다.
