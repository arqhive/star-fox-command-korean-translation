메뉴에 보이는 게임 이름을 한글화한 수정판입니다. 게임 내용과 번역은 v1.0과 같습니다.

**원본 일본판에 적용하는 전체 패치입니다.** 이전 한글 패치 롬에 덧씌울 수 없습니다.

## 변경 사항

- DSi 메뉴, TWiLight Menu++ 등에서 보이는 게임 이름을 "스타폭스 커맨드"로 바꿨습니다. 배너의 6개 언어 칸을 모두 바꾸고 배너 CRC16을 갱신했습니다.

|---|---|---|

## 적용 방법

1. [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)나 Floating IPS로 원본 일본판 롬에 `StarFoxCommand_KO_v1.0.1.bps`를 적용합니다.
2. 결과 롬의 확인값을 아래 표와 비교합니다.

자세한 방법은 첨부한 `README_KO.txt`를 참고하세요.
