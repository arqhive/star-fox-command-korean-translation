# 마침표 검수 가이드

사용자 요청: "텍스트에 마침표가 없어서 언제 문장이 끊어지는지 알 수 없다. 전체 검수해서 마침표를 찍어 달라."

## 규칙
1. **문장이 끝나는 곳에 `.`** 를 붙인다. 평서문·명령문·청유문·감탄 아닌 대답 모두 포함.
   - 예: `알았어` → `알았어.` / `전투 공역 밖에서 대기합니다` → `전투 공역 밖에서 대기합니다.`
   - 한 항목 안에서 줄바꿈 전에 문장이 끝나면 그 줄 끝에도 찍는다: `알았다\n상황은 어떻게 되어 있지?` → `알았다.\n상황은 어떻게 되어 있지?`
2. **찍지 않는 경우**
   - 이미 `?` `!` `...` `~` `…` 등으로 끝나는 문장 (`?!`, `!!` 포함). `...` 뒤에 `.` 추가 금지.
   - **문장이 다음 항목(다음 대화창)으로 이어지는 경우** — 항목 끝이 조사·연결어미(`~을`, `~에게`, `~고`, `~해서`, `~는데` 등)로 끝나면 문장이 아직 안 끝난 것. 반드시 앞뒤 id를 함께 읽고 판단한다.
   - 문장이 아닌 것: 이름, 메뉴/선택지 라벨, 적 이름, 짧은 명사구 표제(`남은 라운드` 등), 효과음·감탄사만 있는 줄(`흐음`, `크윽`)은 문맥상 문장이면 찍고 아니면 두지 않는다.
   - 따옴표로 끝나는 인용문은 `"...했다."`처럼 따옴표 안에 찍는다.
3. **문장 내용은 바꾸지 않는다.** 단, 끝맺음이 불완전해 어색한 문장(예: 문장이 끊긴 채 끝나는데 다음 항목도 없음)은 일본어 원문(`jp`)을 확인해 자연스럽게 마무리하고 보고서에 적는다.
4. 줄 수·줄 폭 제한은 그대로다. 마침표 하나(약 4px)로 폭이 넘치면 뜻을 유지하며 살짝 줄인다.
5. `@1` 치환기호 유지.

## 작업 방법 (대사)
- 작업 폴더 `C:\Users\hgyst\Claude Work\스타 폭스 커맨드\star-fox-command-korean-translation`, Bash는 `export PYTHONIOENCODING=utf-8; cd "/c/Users/hgyst/Claude Work/스타 폭스 커맨드/star-fox-command-korean-translation"`.
- 원문: `work/src/<청크>.json` (jp 원문·en 참고), 번역: `translation/ko/<청크>.json` — **이 파일만 수정**.
- 파이썬으로 JSON을 고칠 때 Bash heredoc 안에 `\n` 문자열을 쓰면 실제 줄바꿈으로 깨진다. 스크립트는 Write 도구로 파일(스크래치패드)에 작성해 실행하거나, 줄바꿈은 `chr(10)`을 쓴다. JSON 저장은 `ensure_ascii=False, indent=1`.
- 끝나면 `python tools/check_ko.py <청크>` 가 **문제 0개**여야 한다.
